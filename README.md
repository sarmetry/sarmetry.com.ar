# sarmetry.com.ar

Sarmetry — Interferometría y teledetección aplicada. Monitoreo y detección de desplazamientos para minería, Oil & Gas e infraestructura.

Sitio estático (una sola página, `index.html`) publicado con GitHub Pages. Dominio gestionado en NIC Argentina y delegado a Cloudflare.

## Estructura

- `index.html` — página única con secciones ancladas (CSS y JS incluidos)
- `logo-completo.svg` — isologo + nombre (encabezado)
- `logo-principal.svg` — logo de nombre (pie de página)
- `hero-hoyo.svg` — gráfico del hero
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-512.png` — íconos
- `og-sarmetry.png` — imagen de vista previa al compartir el link (WhatsApp, redes)
- `CNAME` — dominio personalizado para GitHub Pages
